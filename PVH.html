PVH - Test Report

Isi data, lalu Export. Hasilnya memakai template asli PVH (11 halaman), hanya data yang diisi yang diganti.

Tombol hijau ini nyambungin form ini ke Dashboard. Pilih Overall Rating PASS / FAIL di atas (atau biar Auto, nanti dihitung dari hasil uji), klik ini, status report di Test Reports langsung jalan: Masuk → Proses → Selesai · Pass / Fail. Tombol Mulai proses / Tahan di Dashboard langsung hilang, ganti jadi Selesai · Pass / Fail + Buka lagi. KPI Masuk berkurang, Selesai nambah, diagram QA + Lab Analysis langsung ke-update. Export Excel / PDF juga otomatis nyambung.
